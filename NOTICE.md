# Origins and related work

MessageMotion was extracted and reorganized from an independently developed chat-motion prototype, tuned through user-supplied Messages/sandbox recordings and physical iPhone feedback. Claude performed the recording analysis and the accepted spring/keyboard revisions; Codex prepared the implementation specification, reusable package, independent demo and verification. The project uses public Apple frameworks.

The independent attachment/distance-resistance technique has earlier public examples:

- Ash Furrow, [UICollectionView + UIKit Dynamics](https://www.objc.io/issues/5-ios7/collection-views-and-uidynamics/), objc.io, October2013.
- Robert Hein, [BouncyLayout](https://github.com/roberthein/BouncyLayout), a related open-source spring collection layout.

These are conceptual references, not bundled dependencies. No BouncyLayout source file is redistributed. This project does not claim invention of spring collection views or access to Messages' private implementation. The starting4.5Hz value is a fit inferred from recordings, not an Apple constant.

Private recordings, conversation data, originating business models/assets, credentials and developer signing settings are excluded. The demo text and icon were created for this standalone project. Apple and Messages are referenced descriptively; there is no affiliation or endorsement.
